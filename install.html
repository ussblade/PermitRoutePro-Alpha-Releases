Smaller APKs by device

Not sure which one to use? Choose Universal. Your choice changes the main download buttons. The full universal APK is always available separately.

  1. Download the APK. Use a download button on this page from your Android device.
  2. Open the downloaded file. Android may ask which app should install the package.
  3. Allow this source. If prompted, permit installs from the browser or file manager you used.
  4. Finish installation. Return to the installer and tap Install.
  5. Open Permit Route Pro. Sign in, or create an account and verify your email to start your free trial. Begin with a test permit.
